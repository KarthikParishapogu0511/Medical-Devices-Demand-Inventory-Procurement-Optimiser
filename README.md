# Medical Devices Demand, Inventory & Procurement Optimiser

A full-stack web application for managing medical device inventory, supplier performance, CAPAs, risks, and AI-assisted procurement recommendations.

## Tech Stack

- Frontend: React + Vite
- Backend: Express + Node.js
- Database: SQLite (local file-based)
- AI: Google Gemini API with simulation fallback

## Local Development

### Backend

```bash
cd backend
npm install
cp .env.example .env
node server.js
```

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

- Backend: Render
